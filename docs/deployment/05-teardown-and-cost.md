# 05. コストの見積もりと後片付け

## 無料利用枠との関係

この構成は「ALB + ECS Fargate」ではなく「**EC2単一インスタンス**」を選んでいる。理由は、**ALBとECS Fargateには無料利用枠が存在しない**ため。一方、EC2・RDSには無料利用枠があり、対象のアカウントであれば実質$0に近づけられる。

現在はPhase 2(EC2 + RDS)。S3/CloudFrontはPhase 3(検討中)のため下表には含まれていない(詳細は[03-architecture.md](03-architecture.md))。

| リソース | 無料利用枠 | 対象外の場合の目安月額 |
|---|---|---|
| EC2(t3.micro) | 月750時間・12ヶ月間(対象アカウントの場合) | 約$9〜10 |
| RDS(db.t4g.micro, 20GB, シングルAZ) | 月750時間・12ヶ月間(対象アカウントの場合) | 約$13〜15 |
| ECR | 500MBまで・12ヶ月間 | 超過分のみ(数十円〜) |
| SSM Parameter Store(DBパスワード) | 常に無料(Standard, SecureString含む) | $0 |
| パブリックIPv4アドレス(Elastic IP) | **無料枠なし**。2024年2月以降、稼働中インスタンスに紐づいていても課金される | 約$0.005/時間(月$3.6程度) |
| **合計(無料枠対象の場合)** | **概ね $3.6 / 月**(パブリックIPv4分のみ) | — |
| **合計(無料枠対象外の場合)** | — | **概ね $26〜29 / 月** |

> **「無料枠対象アカウント」かどうかは自分で確認する必要がある**。2025年7月以降に作成されたAWS新規アカウントは、従来の「主要サービスが12ヶ月無料」という制度ではなく、$100(条件達成で最大$200)分のクレジットを消費する方式に変わっている。自分のアカウントがどちらの制度か分からない場合は、AWSコンソールの「Billing and Cost Management」→「Free Tier」ページで確認できる。無料枠クレジットが尽きた後は、上記の「対象外の場合の目安月額」が課金される。

以前検討していたALB + ECS Fargate構成の場合、これに加えて **ALB(約$16/月〜)+ ECS Fargate(約$10/月〜)** が上乗せされ、常時起動で合計$40〜45/月程度になる(無料枠の有無に関わらず)。これがEC2単一インスタンス構成に変更した理由。

DBパスワードの保管にはSecrets Manager(固定費約$0.4/月)ではなく、無料のSSM Parameter Store(SecureString)を使っているため、この構成にSecrets Managerの費用は発生しない。

いずれのリソースも**起動している時間に応じた課金**のため、四六時中動かし続けなければ上記の金額よりずっと安くなる。逆に言えば、**使い終わったら`terraform destroy`で消さない限り、使っていなくても(無料枠の範囲内でなければ)課金され続ける**。

正確な金額は必ず [AWS料金計算ツール](https://calculator.aws) や実際の請求(Billing Dashboard)で確認すること。上記はあくまで目安。

## 学習セッションごとの運用の勧め

1. 動作確認したいときに `terraform apply` でインフラを作る
2. 検証が終わったら `terraform destroy` で削除する
3. 次回また `terraform apply` すれば同じ構成が再現される(これがIaCの利点)

ECR(イメージ)は`destroy`で中身ごと削除されるよう設定してある(`force_delete`)。次回`apply`後に手順2〜3([04-deploy-runbook.md](04-deploy-runbook.md))を再実行してイメージを作り直す想定。

## 削除する

```powershell
cd terraform
terraform plan -destroy   # 何が削除されるか事前確認
terraform destroy
```

確認プロンプトで `yes` を入力する。数分かかることがある(特にRDSの削除)。

完了したら、AWSコンソールの各サービス画面(EC2/RDS/ECR/VPC等)やBilling Dashboardで、意図しないリソースが残っていないか一度目視確認しておくと安心。特にEC2に付与した**Elastic IP**は、上表の通りインスタンスに紐づいていても課金される(月$3.6程度)ため、インスタンス削除後にIPアドレスだけ残っているとさらに無駄な課金になる。`terraform destroy`で両方消えるはずだが、念のためEC2コンソールの「Elastic IP」一覧も確認するとよい。

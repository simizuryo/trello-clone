# 要件定義書 — Trello風タスク管理アプリ (v1)

## 1. 概要
- **背景**: プログラミングスクールの課題として本アプリを開発する。実務上の課題解決を目的としたものではなく、学習目的が主眼である
- **目的**: React + TypeScript + Vite + @dnd-kitを用いたフロントエンド開発を実践的に学ぶこと。コンポーネント設計、状態管理、ドラッグ&ドロップ実装、IndexedDBを用いたブラウザ内DBでのデータ永続化処理といった技術要素を、題材として学習効果の高いTrello風カンバンアプリを通じて一通り習得する
- **スコープ方針**: 学習目的のため、機能の網羅性よりも上記の技術要素を実装しきることを優先し、必要最小限の機能(v1スコープ)に絞る

## 2. 対象ユーザー
- 開発者本人(単一ユーザーでのローカル利用)

## 3. 用語定義
| 用語 | 意味 |
|---|---|
| ボード | カンバン全体を表す最上位の単位(v1では1つのみ) |
| リスト | ボード内の列。カードをグルーピングする(例: 未着手/進行中/完了) |
| カード | 1つのタスクを表す最小単位 |

## 4. 機能要件(v1スコープ)

### 4.1 リスト管理
- リストを追加できる
- リスト名を編集できる
- リストを削除できる(中のカードも一緒に削除される)

### 4.2 カード管理
- カードを追加できる(タイトルのみ。説明文などはv1では持たない)
- カードのタイトルを編集できる
- カードを削除できる
- カードをドラッグ&ドロップで別のリストへ移動できる
- カードを同一リスト内で並び替えできる(ドラッグ&ドロップ)

### 4.3 データ永続化
- ブラウザの IndexedDB にデータを保存する(`idb`ライブラリ経由でPromiseベースに操作)
- ページのリロードやブラウザの再起動後もデータが保持される

## 5. 受け入れ基準

### リスト管理
- [ ] リスト追加ボタン押下で新しいリストが作成され、画面に表示される
- [ ] リスト名を編集すると変更内容が即座に反映される
- [ ] リストを削除すると、そのリスト内の全カードも同時に削除される
- [ ] リスト削除時に確認ダイアログが表示され、キャンセルした場合は削除されない

### カード管理
- [ ] カード追加フォームにタイトルを入力し送信すると、対象リストの末尾にカードが追加される
- [ ] カードタイトルをインライン編集し、フォーカスを外すと変更が保存される
- [ ] カード削除操作で該当カードが即座に一覧から消える
- [ ] カードをドラッグして別リストにドロップすると、移動先リストの指定位置にカードが移動する
- [ ] カードを同一リスト内でドラッグすると、ドロップ位置に応じて並び順が変わる

### データ永続化
- [ ] リスト/カードの追加・編集・削除・並び替えを行った後にページをリロードしても、変更内容が保持されている
- [ ] ブラウザを再起動してアプリを開いても、直前の状態が復元される
- [ ] IndexedDBにデータが存在しない初回起動時は、エラーにならず初期状態(空のボードまたはサンプルデータ)で表示される
- [ ] IndexedDBの初期化(open)に失敗した場合、画面にエラーメッセージが表示される

## 6. 非機能要件
- **動作環境**: Google Chrome, Microsoft Edge, Firefoxの最新安定版(リリースから概ね2バージョン以内)で動作すること。Safariは対象外
- **画面解像度**: 1280×800以上のPC画面を想定。レスポンシブ対応・モバイル最適化はv1では対象外
- **パフォーマンス**: リスト数10、カード数各リスト50件程度(合計500件)までは、操作時にストレスのない応答速度(体感で200ms以内)で動作すること
- **データ保存容量**: IndexedDBはlocalStorageのような5MB程度の制限を受けず、ブラウザの空き容量に応じて数百MB〜GB単位まで保存可能。本アプリの想定データ量(リスト10・カード合計500件程度)では実質制限にならない
- **エラー時の挙動**:
  - IndexedDBの初期化(`open`)に失敗した場合は、画面にエラーメッセージを表示する
  - トランザクションの読み書きに失敗した場合は、コンソールにエラーログを出力し、画面上に保存失敗を示すメッセージを表示する
- サーバー・データベース不要、フロントエンドのみで完結
- ユーザー認証なし(単一ユーザー・ローカル利用前提)
- アクセシビリティ: v1では特別な対応を行わない(将来課題)

## 7. データモデル(案)
```
List: { id: string, title: string, order: number }
Card: { id: string, listId: string, title: string, order: number }
```

IndexedDBのobject store構成(案):
```
DB: "trello-clone-db"
  ObjectStore "lists"   keyPath: "id"
    { id: string, title: string, order: number }
  ObjectStore "cards"   keyPath: "id", index: "listId"
    { id: string, listId: string, title: string, order: number }
```

## 8. 画面構成・画面イメージ

- ボード画面(1画面のみ)
  - 上部: アプリタイトル
  - 中央: リストを横に並べたカンバンビュー
  - 各リスト: ヘッダー(タイトル + 削除ボタン) / カード一覧 / 「カードを追加」入力欄
  - 一覧の右端: 「リストを追加」ボタン

```
+--------------------------------------------------------------------+
|  Trello風タスク管理アプリ                                          |
+--------------------------------------------------------------------+
|  +-------------+   +-------------+   +-------------+   +---------+ |
|  | 未着手  [×] |   | 進行中  [×] |   | 完了    [×] |   |         | |
|  +-------------+   +-------------+   +-------------+   |         | |
|  | [カード1  ] |   | [カード3  ] |   | [カード5  ] |   |         | |
|  | [カード2  ] |   | [カード4  ] |   |             |   | +リスト | |
|  |             |   |             |   |             |   |  を追加 | |
|  | + カード追加 |   | + カード追加 |   | + カード追加 |   |         | |
|  +-------------+   +-------------+   +-------------+   +---------+ |
+--------------------------------------------------------------------+
```

- 各カードはカード全体をドラッグハンドルとして掴んで移動可能
- リストヘッダーの[×]ボタンでリスト削除(確認ダイアログを挟む)
- カードタイトルはクリックでインライン編集モードに切り替え

## 9. 技術スタック
- React + TypeScript + Vite
- ドラッグ&ドロップ: `@dnd-kit`(リスト内並び替え・リスト間移動の両方に対応)
- 状態管理: React標準の `useState` / `useContext`(v1では外部ライブラリ不要)
- データ保存: ブラウザ `IndexedDB`(`idb`ライブラリでPromiseベースにラップして利用)

## 10. スコープ外(v1では対応しない・将来の拡張候補)
- 複数ボードの管理
- カード詳細(説明文、期限、ラベル、担当者、添付ファイル、チェックリスト)
- ユーザー認証・複数人でのリアルタイム共有
- サーバーサイド保存(DB連携)
- 検索・フィルター機能
- 通知機能

## 11. 拡張ロードマップ(参考)
- v2: カード詳細(説明・期限)を追加
- v3: 複数ボード対応
- v4: バックエンド連携(DB保存、複数人での共有)

## 14. 要確認ポイント
以下は今回の会話からは明確でなかったため、暫定でこう決めた、という点です。認識が違えば教えてください。

1. **リスト自体の並び替え**は要件に含めていません(カードの並び替えのみ)。リストの順番も変更したい場合は追加します。
2. カードクリック時の詳細表示・編集モーダルなどはv1では作らず、タイトルはインライン編集想定です。
3. リストの削除時に「本当に削除しますか」の確認ダイアログを出す想定です(誤操作防止)。

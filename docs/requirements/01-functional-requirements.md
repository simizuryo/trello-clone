# 機能要件・受け入れ基準

## 4. 機能要件(v1スコープ)

### 4.1 リスト管理
- リストを追加できる
- リスト名を編集できる
- リストを削除できる(中のカードも一緒に削除される)

### 4.2 カード管理
- カードを追加できる(タイトルのみ。説明文などはv1では持たない)
- カードのタイトルを編集できる
- カードを削除できる
- カードをドラッグ&ドロップで別のリストへ移動できる
- カードを同一リスト内で並び替えできる(ドラッグ&ドロップ)

### 4.3 データ永続化
- ブラウザの IndexedDB にデータを保存する(`idb`ライブラリ経由でPromiseベースに操作)
- ページのリロードやブラウザの再起動後もデータが保持される

## 5. 受け入れ基準

### リスト管理
- [ ] リスト追加ボタン押下で新しいリストが作成され、画面に表示される
- [ ] リスト名を編集すると変更内容が即座に反映される
- [ ] リストを削除すると、そのリスト内の全カードも同時に削除される
- [ ] リスト削除時に確認ダイアログが表示され、キャンセルした場合は削除されない

### カード管理
- [ ] カード追加フォームにタイトルを入力し送信すると、対象リストの末尾にカードが追加される
- [ ] カードタイトルをインライン編集し、フォーカスを外すと変更が保存される
- [ ] カード削除操作で該当カードが即座に一覧から消える
- [ ] カードをドラッグして別リストにドロップすると、移動先リストの指定位置にカードが移動する
- [ ] カードを同一リスト内でドラッグすると、ドロップ位置に応じて並び順が変わる

### データ永続化
- [ ] リスト/カードの追加・編集・削除・並び替えを行った後にページをリロードしても、変更内容が保持されている
- [ ] ブラウザを再起動してアプリを開いても、直前の状態が復元される
- [ ] IndexedDBにデータが存在しない初回起動時は、エラーにならず初期状態(空のボードまたはサンプルデータ)で表示される
- [ ] IndexedDBの初期化(open)に失敗した場合、画面にエラーメッセージが表示される

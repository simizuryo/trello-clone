# 機能要件・受け入れ基準

## 4. 機能要件(v1スコープ)

### 4.1 リスト管理
- リストを追加できる
- リスト名を編集できる
- リストを削除できる(中のカードも一緒に削除される)

### 4.2 カード管理
- カードを追加できる(タイトル・優先度・期限を持つ。説明文などはそれ以外はv1では持たない)
  - 優先度: 高・中・低の3段階(未設定可)
  - 期限: 日付(未設定可)
- カードのタイトル・優先度・期限を編集できる
- カードを削除できる
- カードをドラッグ&ドロップで別のリストへ移動できる
- カードを同一リスト内で自由に並び替えできる(ドラッグ&ドロップ)。この自由並び替えは常時可能で、下記のソート機能を使った後も引き続き利用できる

### 4.3 ソート機能
- リストごとに「優先順」「期限順」ボタンを設置する
- ボタン押下時点でそのリスト内のカードを一括で並び替える(優先順: 高→低、期限順: 近い→遠い、未設定は末尾)
- これはワンショットの整列操作であり、以後は自動で順序を維持し続けるモードには入らない。ソート後もユーザーはドラッグ&ドロップで自由に並び替えできる

### 4.4 データ永続化
- ブラウザの IndexedDB にデータを保存する(`idb`ライブラリ経由でPromiseベースに操作)
- ページのリロードやブラウザの再起動後もデータが保持される

## 5. 受け入れ基準

### リスト管理
- [ ] リスト追加ボタン押下で新しいリストが作成され、画面に表示される
- [ ] リスト名を編集すると変更内容が即座に反映される
- [ ] リストを削除すると、そのリスト内の全カードも同時に削除される
- [ ] リスト削除時に確認ダイアログが表示され、キャンセルした場合は削除されない

### カード管理
- [ ] カード追加フォームにタイトルを入力し送信すると、対象リストの末尾にカードが追加される(優先度・期限は未設定で作成可能)
- [ ] カードタイトルをインライン編集し、フォーカスを外すと変更が保存される
- [ ] カードの優先度・期限を編集すると変更が即座に反映される
- [ ] カード削除操作で該当カードが即座に一覧から消える
- [ ] カードをドラッグして別リストにドロップすると、移動先リストの指定位置にカードが移動する
- [ ] カードを同一リスト内でドラッグすると、ドロップ位置に応じて並び順が変わる

### ソート機能
- [ ] 「優先順」ボタンを押すと、そのリスト内のカードが優先度の高い順に並び替わる(未設定は末尾)
- [ ] 「期限順」ボタンを押すと、そのリスト内のカードが期限の近い順に並び替わる(未設定は末尾)
- [ ] ソートボタン押下後も、カードをドラッグ&ドロップして自由に並び替えることができる(自動再ソートされない)

### データ永続化
- [ ] リスト/カードの追加・編集・削除・並び替えを行った後にページをリロードしても、変更内容が保持されている
- [ ] ブラウザを再起動してアプリを開いても、直前の状態が復元される
- [ ] IndexedDBにデータが存在しない初回起動時は、エラーにならず初期状態(空のボードまたはサンプルデータ)で表示される
- [ ] IndexedDBの初期化(open)に失敗した場合、画面にエラーメッセージが表示される

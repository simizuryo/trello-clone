# 概要・対象ユーザー・用語定義

## 1. 概要
- **背景**: プログラミングスクールの課題として本アプリを開発する。実務上の課題解決を目的としたものではなく、学習目的が主眼である
- **目的**: React + Vite + @dnd-kitを用いたフロントエンド開発を実践的に学ぶこと。コンポーネント設計、状態管理、ドラッグ&ドロップ実装、IndexedDBを用いたブラウザ内DBでのデータ永続化処理といった技術要素を、題材として学習効果の高いTrello風カンバンアプリを通じて一通り習得する(v1はTypeScriptを使わずJavaScriptで実装)。将来的にはJava + Spring Boot + PostgreSQLによるバックエンド連携も学習範囲として拡張する予定
- **スコープ方針**: 学習目的のため、機能の網羅性よりも上記の技術要素を実装しきることを優先し、必要最小限の機能(v1スコープ)に絞る

## 2. 対象ユーザー
- 開発者本人(単一ユーザーでのローカル利用)

## 3. 用語定義
| 用語 | 意味 |
|---|---|
| ボード | カンバン全体を表す最上位の単位(v1では1つのみ) |
| リスト | ボード内の列。カードをグルーピングする(例: 未着手/進行中/完了) |
| カード | 1つのタスクを表す最小単位 |

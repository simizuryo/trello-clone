# 非機能要件

## 6. 非機能要件
- **動作環境**: Google Chrome, Microsoft Edge, Firefoxの最新安定版(リリースから概ね2バージョン以内)で動作すること。Safariは対象外
- **画面解像度**: 1280×800以上のPC画面を想定。レスポンシブ対応・モバイル最適化はv1では対象外
- **パフォーマンス**: リスト数10、カード数各リスト50件程度(合計500件)までは、操作時にストレスのない応答速度(体感で200ms以内)で動作すること
- **データ保存容量**: IndexedDBはlocalStorageのような5MB程度の制限を受けず、ブラウザの空き容量に応じて数百MB〜GB単位まで保存可能。本アプリの想定データ量(リスト10・カード合計500件程度)では実質制限にならない
- **エラー時の挙動**:
  - IndexedDBの初期化(`open`)に失敗した場合は、画面にエラーメッセージを表示する
  - トランザクションの読み書きに失敗した場合は、コンソールにエラーログを出力し、画面上に保存失敗を示すメッセージを表示する
- サーバー・データベース不要、フロントエンドのみで完結
- ユーザー認証なし(単一ユーザー・ローカル利用前提)
- アクセシビリティ: v1では特別な対応を行わない(将来課題)

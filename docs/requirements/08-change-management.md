# 変更管理

## 13. 変更管理
- 本ドキュメントの内容に変更が生じた場合は、該当ファイルを更新したうえで、下記の変更履歴に追記する
- [スコープ外](06-scope-and-roadmap.md)の機能を追加したくなった場合は、まず該当ファイルに追記してから実装に着手する

### 変更履歴
| 日付 | 変更内容 | 理由 |
|---|---|---|
| 2026-07-30 | 背景・目的をスクール課題(学習目的)向けに更新 | 実務課題ではなく学習目的であることを明確化するため |
| 2026-07-30 | 受け入れ基準、画面イメージ、非機能要件の具体化、スケジュール・成果物、変更管理を追加 | 学習用ドキュメントとしての完成度を高めるため |
| 2026-07-30 | データ永続化をlocalStorageからIndexedDB(`idb`ライブラリ)に変更 | バックエンドを持たずに実際のDB操作(object store・transaction)を学習するため |
| 2026-07-30 | 要件定義書を項目ごとに複数ファイルへ分割 | ドキュメントの見通しと保守性を高めるため |
| 2026-08-02 | カードに優先度・期限フィールドを追加し、優先順・期限順のワンショットソートボタンを追加。自由なドラッグ&ドロップ並び替えは常時可能とする | 実際のTrelloのように、自動ソートだけでなく自由な手動並び替えも両立させたいという要望のため |
| 2026-08-02 | v1のフロントエンドをReact + TypeScriptからReact + JavaScriptへ変更(TypeScriptは今回対象外) | 学習範囲の調整のため |
| 2026-08-02 | 将来のバックエンド構成としてJava + Spring Boot + PostgreSQLをロードマップ(v4)に追加 | バックエンド技術の学習も将来範囲に含めたいという要望のため。v1のスコープ(フロントエンドのみ・IndexedDB永続化)自体は変更しない |

# 画面構成・画面イメージ

## 8. 画面構成・画面イメージ

アプリ上部のタブで2つの画面を切り替える構成(v4のバックエンド連携により、当初の「ボード画面(1画面のみ)」から拡張)。

| 画面 | データ永続化先 | 特徴 |
|---|---|---|
| マイボード | ブラウザ`IndexedDB` | 8.1節の元々のカンバンビュー。リスト/カードの追加・編集・削除・並び替え・ワンショットソートがすべて利用可能 |
| 検索(サーバー) | Spring Boot REST API 経由の PostgreSQL | 8.2節。キーワード・優先度・リストでの検索/絞り込みに加え、カードの追加・インライン編集・ドラッグ&ドロップでの並び替え・リスト間移動が可能。カードの削除のみ未実装 |

### 8.1 マイボード画面
- 上部: アプリタイトル + 画面切り替えタブ
- 中央: リストを横に並べたカンバンビュー
- 各リスト: ヘッダー(タイトル + 削除ボタン) / ソートボタン(優先順・期限順) / カード一覧 / 「カードを追加」入力欄
- 各カード: タイトル + 優先度バッジ + 期限表示
- 一覧の右端: 「リストを追加」ボタン

```
+--------------------------------------------------------------------+
|  Trello風タスク管理  [マイボード][検索(サーバー)]                  |
+--------------------------------------------------------------------+
|  +-------------+   +-------------+   +-------------+   +---------+ |
|  | 未着手  [×] |   | 進行中  [×] |   | 完了    [×] |   |         | |
|  | [優先順][期限順]| | [優先順][期限順]| | [優先順][期限順]| |         | |
|  +-------------+   +-------------+   +-------------+   |         | |
|  | [カード1  ] |   | [カード3  ] |   | [カード5  ] |   |         | |
|  | 高 8/10     |   | 中 8/05     |   |             |   | +リスト | |
|  | [カード2  ] |   | [カード4  ] |   |             |   |  を追加 | |
|  |             |   |             |   |             |   |         | |
|  | + カード追加 |   | + カード追加 |   | + カード追加 |   |         | |
|  +-------------+   +-------------+   +-------------+   +---------+ |
+--------------------------------------------------------------------+
```

- 各カードはカード全体をドラッグハンドルとして掴んで移動可能
- リストヘッダーの[×]ボタンでリスト削除(確認ダイアログを挟む)
- カードタイトルはクリックでインライン編集モードに切り替え(優先度・期限も同じ編集モードでまとめて変更)
- 「優先順」「期限順」ボタンはワンショットの並び替えで、押した瞬間だけそのリスト内のカード順を書き換える。押した後も引き続きドラッグ&ドロップで自由に並び替え可能(ボタンは特別なモードに入るわけではない)

### 8.2 検索(サーバー)画面
- 上部: アプリタイトル + 画面切り替えタブ + 検索バー(キーワード入力 / 優先度セレクト / リストセレクトの3つの絞り込み条件、AND条件)
- 中央: マイボードと同様のカンバンビュー(検索・絞り込み結果のリスト/カードを表示)。ただし各リストにソートボタン・削除ボタンは無く、各カードにも削除ボタンは無い
- 一覧の右端: 「リストを追加」ボタン(マイボードと共通)

```
+--------------------------------------------------------------------+
|  Trello風タスク管理  [マイボード][検索(サーバー)]                  |
+--------------------------------------------------------------------+
|  [キーワードで検索        ] [優先度: すべて v] [リスト: すべて v]  |
+--------------------------------------------------------------------+
|  +-------------+   +-------------+   +-------------+   +---------+ |
|  | Todo        |   | In Progress |   | Done        |   |         | |
|  +-------------+   +-------------+   +-------------+   |         | |
|  | [カード1  ] |   | [カード3  ] |   | [カード5  ] |   |         | |
|  | 高 8/10     |   | 中 8/05     |   |             |   | +リスト | |
|  | [カード2  ] |   | [カード4  ] |   |             |   |  を追加 | |
|  |             |   |             |   |             |   |         | |
|  | + カード追加 |   | + カード追加 |   | + カード追加 |   |         | |
|  +-------------+   +-------------+   +-------------+   +---------+ |
+--------------------------------------------------------------------+
```

- キーワード検索は入力から一定時間後に自動で検索を実行する(デバウンス)。優先度・リストの絞り込みは選択と同時に反映される
- カードタイトルはクリックでインライン編集モードに切り替え(マイボードと同じUI)。ドラッグ&ドロップでの並び替え・リスト間移動も可能で、「完了」を表すリストへの移動が完了切替を兼ねる
- 「完了」を表すリストへ移動する以外の完了フラグ切り替えUIは持たない(独立した完了フラグは無い)
- カードの削除ボタンは無い(未実装。別Issueで対応予定)

# 画面構成・画面イメージ

## 8. 画面構成・画面イメージ

- ボード画面(1画面のみ)
  - 上部: アプリタイトル
  - 中央: リストを横に並べたカンバンビュー
  - 各リスト: ヘッダー(タイトル + 削除ボタン) / カード一覧 / 「カードを追加」入力欄
  - 一覧の右端: 「リストを追加」ボタン

```
+--------------------------------------------------------------------+
|  Trello風タスク管理アプリ                                          |
+--------------------------------------------------------------------+
|  +-------------+   +-------------+   +-------------+   +---------+ |
|  | 未着手  [×] |   | 進行中  [×] |   | 完了    [×] |   |         | |
|  +-------------+   +-------------+   +-------------+   |         | |
|  | [カード1  ] |   | [カード3  ] |   | [カード5  ] |   |         | |
|  | [カード2  ] |   | [カード4  ] |   |             |   | +リスト | |
|  |             |   |             |   |             |   |  を追加 | |
|  | + カード追加 |   | + カード追加 |   | + カード追加 |   |         | |
|  +-------------+   +-------------+   +-------------+   +---------+ |
+--------------------------------------------------------------------+
```

- 各カードはカード全体をドラッグハンドルとして掴んで移動可能
- リストヘッダーの[×]ボタンでリスト削除(確認ダイアログを挟む)
- カードタイトルはクリックでインライン編集モードに切り替え

# スコープ外・拡張ロードマップ

## 10. スコープ外(v1では対応しない・将来の拡張候補)
- 複数ボードの管理
- カード詳細(説明文、期限、ラベル、担当者、添付ファイル、チェックリスト)
- ユーザー認証・複数人でのリアルタイム共有
- サーバーサイド保存(DB連携)
- 検索・フィルター機能
- 通知機能

# 要確認ポイント

## 14. 要確認ポイント
以下は今回の会話からは明確でなかったため、暫定でこう決めた、という点です。認識が違えば教えてください。

1. **リスト自体の並び替え**は要件に含めていません(カードの並び替えのみ)。リストの順番も変更したい場合は追加します。
2. カードクリック時の詳細表示・編集モーダルなどはv1では作らず、タイトル・優先度・期限はインライン編集想定です。
3. リストの削除時に「本当に削除しますか」の確認ダイアログを出す想定です(誤操作防止)。
4. 優先度・期限のソートボタンは**ワンショットの並び替え**であり、「常に優先度順を維持する」ような自動ソートモードではない、という理解で進めています。ソート後も自由なドラッグ&ドロップ並び替えを常に優先します。
